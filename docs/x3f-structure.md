# X3F 是完全独立的私有格式

结构是这样的:

**文件头** (File Header)
- 签名 "FOVb" (Foveon B型) 或其他版本标识
- 版本号
- 指向目录段的指针

**目录段** (Directory Section)
- 包含多个目录条目
- 每个条目指向具体数据段的位置和类型

**数据段** (Data Sections)
- **IMAG** - 图像数据(三层 Foveon 数据)
- **IMA2** - 预览/缩略图
- **PROP** - 属性数据(相机设置、拍摄参数)
- **CAMF** - 相机格式特定信息

X3F 本身**没有标准 EXIF**。拍摄参数都存在 PROP 段里,是 Sigma 自己定义的键值对格式。

如果你用某些软件转换 X3F 后看到 EXIF,那是软件**后加的**,不是原始文件里的。LibRaw 读 X3F 时会把 PROP 段的信息"翻译"成类似 EXIF 的结构给你,但原始文件里根本没有 EXIF 容器。

这也是为什么 X3F 兼容性差——完全是私有封闭格式,没用任何标准容器。
