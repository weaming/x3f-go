# Quattro 传感器数据融合算法详解

## 摘要

本文档旨在从算法层面，详细解释适马 Quattro 传感器独特的 1:1:4 数据融合过程。需要明确的是，适马官方的 TRUE III 引擎所使用的具体算法是商业机密。但是，这个过程在图像处理领域属于一个经典问题，通常被称为**“引导式图像上采样” (Guided Image Upsampling)** 或 **“全色锐化” (Pansharpening)**。本文将通过一个标准的、效果很好的公开算法——**引导滤波器 (Guided Filter)** 的原理来分步解释这个过程。

## 准备阶段：数据分离与色彩空间转换

算法的输入不是直接可用的“亮度”和“色度”，而是我们从 X3F 文件中解码出的三个原始感光层：

- **顶层 (`B_high`)**: `W x H` 分辨率 (例如 5424x3616)，拥有最高的细节。
- **中层 (`G_low`)**: `(W/2) x (H/2)` 分辨率 (例如 2712x1808)，分辨率较低。
- **底层 (`R_low`)**: `(W/2) x (H/2)` 分辨率 (例如 2712x1808)，分辨率较低。

### 步骤 0：数据预处理

1.  **初步上采样**：首先，使用一种基础的插值算法（如双三次插值 Bicubic），将低分辨率的 `G_low` 和 `R_low` 放大到与顶层相同的 `W x H` 尺寸，得到 `G_interp` 和 `R_interp`。这一步得到的图像色彩是模糊的，但尺寸已经对齐。

2.  **色彩空间转换**：Foveon 传感器的 R, G, B 通道色彩交叉污染严重，直接使用并不理想。我们需要将 `(B_high, G_interp, R_interp)` 这三层数据，通过一个 3x3 的色彩校正矩阵（从 `CAMF` 元数据中获得），转换到一个更适合处理亮度/色度分离的色彩空间，例如 **YCbCr**。
    - **Y (亮度)**: 主要由高分辨率的 `B_high` 贡献，包含了图像的绝大部分细节。我们得到一个高分辨率的亮度通道 `Y_high`。
    - **Cb, Cr (色度)**: 主要由 `G_interp` 和 `R_interp` 贡献，包含了图像的色彩信息。由于它们的来源是低分辨率的，所以我们实际上只需要它们的低分辨率版本 `Cb_low` 和 `Cr_low`（可以通过对转换后的高分辨率色度通道进行降采样得到）。

**至此，我们得到了算法真正的输入：**

- **引导图像 (Guidance Image)**: `Y_high` (`W x H`)
- **待上采样图像 (Input Image)**: `Cb_low` 和 `Cr_low` (`(W/2) x (H/2)`)

---

## 核心阶段：引导式色度上采样

这是整个融合过程的“魔法”所在。我们将对 `Cb` 和 `Cr` 两个色度通道分别执行相同的操作。以下以 `Cb` 通道为例。

**目标：利用 `Y_high` 的细节，将 `Cb_low` “智能地”放大成高分辨率的 `Cb_high`。**

### 步骤 1：建立低分辨率下的线性模型

- **核心假设**: 引导滤波器算法假设，在一个小的局部窗口内，引导图像（亮度）和目标图像（色度）之间存在线性关系。即：`色度 ≈ a * 亮度 + b`。
- **降采样引导图**: 为了在低分辨率下进行计算，我们将高分辨率的 `Y_high` 降采样到与 `Cb_low` 相同的尺寸，得到 `Y_low`。
- **计算线性系数**: 算法遍历低分辨率图像 (`Y_low` 和 `Cb_low`) 上的每一个小窗口（例如 3x3 或 5x5 的像素块）。在每个窗口 `k` 内，通过**线性回归**，计算出最佳的 `a_k` 和 `b_k` 值，使得 `a_k * Y_low + b_k` 的结果与真实的 `Cb_low` 在这个窗口内最接近。
  - `a_k` 代表了这个窗口内，亮度和色度的相关性（例如，亮度越高，蓝色是越深还是越浅）。
  - `b_k` 代表了这个窗口的基础色度。

### 步骤 2：将模型应用到高分辨率

- **放大系数**: 我们现在有了一组在低分辨率下计算出的 `a_k` 和 `b_k` 系数。我们将这些系数进行上采样，得到两张与 `Y_high` 同样大小的“系数图”：`A_high` 和 `B_high`。这样，高分辨率图像中的每一个像素点，都有了自己专属的 `a` 和 `b` 值。
- **合成高分辨率色度**: 现在，我们可以应用线性模型来合成最终的高分辨率色度通道了。对于高分辨率图像中的每一个像素 `i`：
  `Cb_high(i) = A_high(i) * Y_high(i) + B_high(i)`

  这个公式的含义是：用高分辨率的亮度细节 (`Y_high`)，去“调制”我们计算出的局部色彩模型 (`A_high`, `B_high`)，从而重建出高分辨率的色度细节。这精确地实现了“用高清素描稿的轮廓来指导上色”的思路。

### 步骤 3：重复与合并

- 对另一个色度通道 `Cr_low` 重复上述**步骤 1 和 2**，得到高分辨率的 `Cr_high`。
- 现在我们拥有了三个尺寸完全相同 (`W x H`) 且细节完美对齐的通道：`Y_high`, `Cb_high`, `Cr_high`。

---

## 输出阶段：图像最终合成

### 步骤 4：转换回 RGB

- 将 `(Y_high, Cb_high, Cr_high)` 通过一个逆色彩矩阵，转换回我们最终想要的标准 RGB 色彩空间（例如 sRGB）。
- `RGB_high = M * [Y_high, Cb_high, Cr_high]`

至此，整个融合过程完成，我们得到了一张细节锐利、色彩饱满的高分辨率彩色图像。

## 总结

这个算法的精妙之处在于，它没有凭空创造细节，而是基于一个核心假设：**图像的结构（边缘、纹理）在亮度和色度通道中是相似的**。它从高分辨率的亮度通道中“借用”了结构信息，并用它来指导低分辨率的色度通道应该如何在细节处进行填充，完美地实现了“给高清素描稿上色”这一比喻。
